# Media Files Setup

To customize this premium experience, replace the placeholder files in this directory with your actual images, videos, and music. 
Make sure you **keep the exact same filenames** so the code can find them!

## Required Files to Add Here:

### 1. The Main Romantic Song
- Rename your main love song to `song.mp3`
- Place it in this folder.

### 2. The Video
- Rename his video to `video1.mp4`
- Place it in this folder.
- (If it's large, consider compressing it for better web performance)

### 3. The Images
- Find 3 beautiful images of him/them.
- Rename them to:
  - `image1.jpg`
  - `image2.jpg`
  - `image3.jpg`
- Place them in this folder.

*Note: For now, the app will run even if these are missing, but it might show black squares until you add your actual files.*
